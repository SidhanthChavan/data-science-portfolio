## Projects

### UK used-car price prediction

Two coursework notebooks exploring regression on approximately 400,000 vehicle listings. The first compares baseline models; the second examines ensemble methods, feature selection and model interpretation.

[View repository](https://github.com/SidhanthChavan/UK-Used-Car-Price-Prediction)

### Deepfake detection prototype

An MSc dissertation prototype built around EfficientNet-B4 and ResNet-18 backbones. The repository includes frame extraction, face detection, model training and Grad-CAM experiments performed on a subset of a larger audio-visual deepfake dataset.

[View repository](https://github.com/SidhanthChavan/deepfake-detection-efficientnet)

### Commercial energy cost analysis

A synthetic scenario-modelling exercise examining how assumed non-commodity electricity charges change with annual consumption. The repository is retained as an exploratory analysis, not as current regulatory guidance.

[View repository](https://github.com/SidhanthChavan/Commercial-Energy-Cost-Optimisation)

### Rice leaf disease classification

A small transfer-learning experiment using ResNet-18 to classify three rice leaf conditions. This is an academic prototype based on a limited public image dataset.

[View repository](https://github.com/SidhanthChavan/Rice-Leaf-Disease-Detection)
